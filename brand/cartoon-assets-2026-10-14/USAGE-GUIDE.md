# Cartoon asset studio — MenuMate / Nextward

Each brand pack contains **20 unique assets**. SVG and PNG versions of the same illustration count as one asset.

## Start here
Open `START-HERE.html` in your browser for a visual catalog. It works offline. Switch between light/dark backgrounds to check cutout edges, and enable gentle motion for a simple movement preview. This is not a rendered video.

- `svg/01–16`: editable vector artwork, with named groups for reusable parts.
- `png/01–16`: matching transparent PNG exports for video editors.
- `png/17–18`: detailed transparent mascot illustrations.
- `png/19–20`: landscape and portrait scene backgrounds.
- Contact sheets: quick asset selection.
- Individual manifest / README: asset names, intended uses, technical notes.

## Editing and animation
SVG files can be opened in Figma, Illustrator or Inkscape. Keep an untouched source copy. Preserve the viewBox when recoloring or exporting. Named groups make it easier to select heads, arms, props and decorative accents; this is an editable illustration system, not an automatic character rig.

For a quick explainer in CapCut, Premiere, Resolve or similar:
1. Place a background on the bottom track.
2. Add a character PNG above it. Keep the face clear of captions.
3. Add a relevant prop or SVG-derived PNG on a separate track.
4. Use a small entrance move, gentle scale change or short rotation. Avoid stretching the character.
5. Add real screen recordings or verified UI screenshots separately when teaching actual product steps.
6. Add your own captions in the editor so they remain editable and accessible.

PNG characters are flattened: independently moving limbs requires manual separation or an SVG character. Importing SVG layers into a video editor may require converting shapes or exporting pieces. Video software support varies.

## Layout tips
- Landscape scenes: use for 16:9 explainers; preserve their intended empty caption area.
- Portrait scenes: use for vertical stories/reels; keep critical content away from app interface overlays.
- Transparent cutouts: preview over the actual video background before export.
- SVG scaling is resolution-independent; raster PNG scaling is limited by its native dimensions.
