# Nextward flat cartoon collection 02

Six additional illustrations created on 13 October 2026 with the built-in image generation tool, continuing the approved flat cartoon style from `../flat-cartoon/`. Each asset is text-free with real alpha transparency, simple rounded adult characters and Nextward's existing palette.

| File | Use |
|---|---|
| `01-portfolio-builder` | Profile creation, CV preparation, and showcasing skills. |
| `02-interview-ready` | Interview preparation, application progress, and professional confidence. |
| `03-meaningful-connections` | Networking, messaging, introductions, or community sections. |
| `04-skill-builder` | Career guides, ongoing learning, and skill development. |
| `05-find-your-direction` | Career changes, exploring options, and guidance. |
| `06-offer-moment` | Accepted offers, successful applications, milestones, or a closing video scene. |

Every illustration includes a PNG original for video composition and a smaller WebP export for the website. The networking scene is 1536 × 1024; the other five are 1254 × 1254. Keep full subjects visible using contain sizing.

[preview.html](preview.html) shows the set on cream, navy and white backgrounds. Exact generation prompts are in [prompts.json](prompts.json). Dimensions, file sizes and alpha checks are in [manifest.json](manifest.json).

Public asset URLs start with `/nextward-assets/flat-cartoon-02/`. Use PNGs as transparent still layers or image-to-video references. These are flattened raster images, not rigged characters or editable vectors. Add headlines and the existing logo separately.

Palette: cobalt `#2563EB`, navy `#0A1738`, periwinkle `#DCE8FC`, cream `#FAF9F6`, terracotta `#E78955`, and natural skin tones. All people are fictional illustrations. Website code and previous assets were not modified.
