# Nextward flat cartoon collection

Six new illustrations created on 13 October 2026 with the built-in image generation tool. This set uses rounded geometric characters, simple faces and bold shapes, with Nextward's cobalt, navy, cream, powder blue and terracotta colors. Each asset is text-free with real alpha transparency.

| File | Use |
|---|---|
| `01-opportunity-explorer` | Discovery, opportunity search, or an opening video character. |
| `02-professional-on-the-move` | Professional audience sections, career momentum, or animated walk-on. |
| `03-remote-creator` | Remote work, flexible opportunities, or a calm video moment. |
| `04-focused-designer` | Inclusive work imagery, candidate sections, or a standalone video character. |
| `05-next-chapter` | Career changes, returning to work, or a transition scene. |
| `06-better-together` | Employer sections, community, team building, or a closing video scene. |

Each file is available as a PNG original for video compositing and a smaller WebP export for the website. The first four are 1254 × 1254; the last two are 1536 × 1024. Keep complete subjects visible with contain sizing.

Open [preview.html](preview.html) to see all six against cream, navy or white. Exact prompts are saved in [prompts.json](prompts.json). Dimensions, sizes and alpha checks are listed in [manifest.json](manifest.json).

Website URLs start with `/nextward-assets/flat-cartoon/`. Use the PNGs as still layers or image-to-video references; these are flattened images, not rigged characters or editable vector files. Add headings and the existing Nextward logo separately. All people are fictional illustrations.

This collection is separate from the earlier editorial assets. Application code and previous assets were not changed.
