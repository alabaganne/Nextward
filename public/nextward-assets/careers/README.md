# Nextward career assets
Created 13 October 2026 using the built-in image generation tool.

Six original editorial illustrations extending the current [Nextward landing page](https://nextward.alabaganne.com/) to students and experienced professionals. Style reference: the existing `landing/career-steps.webp`. All files are text-free with real alpha transparency.

## Website
Use WebP with the complete image visible. The intended primary canvas is warm cream `#FAF9F6` or white. Navy works as an alternate, but dark clothing has less contrast there. The WebP exports use quality 86 with the original alpha preserved exactly; they range from 75 to 194 KiB.

## Video
Use PNG originals as transparent still layers or references for image-to-video generation. The two standalone people are separate full-body assets; the four scene illustrations are flattened compositions, not layered or rigged character files. Add titles and the existing Nextward logo separately. Keep complete figures visible, use gentle pans or push-ins, and avoid stretching. No animation or video files are included.

## Brand
Cobalt `#2563EB`, navy `#0A1738`, powder blue `#DCE8FC`, cream `#FAF9F6`, and terracotta `#E78955`. Follow the current website's Space Grotesk display type and Plus Jakarta Sans body type for separately composed text. The people are illustrations, not real customer portraits.
